### [VrShare](https://github.com/TurabDevs/VrShare)

**Free LAN file sharing, clipboard sync & remote PC control — Windows + Android.**

<br/>

| 📁 File Sharing | 📋 Clipboard Sync |
|:---:|:---:|
| Send files phone ↔ PC over your own Wi-Fi | Copy on one device, paste on the other |

| 🖱️ Remote Control | 💻 PC Power |
|:---:|:---:|
| Phone as mouse & keyboard | Lock, sleep, shutdown, restart remotely |

🔒 **PIN pairing + certificate pinning** — your files never leave your network.

*Built with **Rust (Tauri v2)** on desktop, **Kotlin** on Android.*
